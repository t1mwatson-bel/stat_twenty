OLD HOCKEY ML — запуск

Файлы:
- bot.py — основной цикл Telegram-бота, Ruscore/1xBet, отправка и проверка прогнозов
- config.py — настройки и переменные окружения
- model.py — обучение ML и выбор прогноза (RandomForest; fallback на исходную статистику)
- web_server.py — сайт статистики Flask
- requirements.txt — зависимости

Установка:
1. Загрузите все файлы в одну папку на хостинге.
2. Установите зависимости: pip install -r requirements.txt
3. Добавьте переменные окружения из .env.example в панели хостинга. Не вставляйте ключи прямо в код.
4. Укажите стартовый файл bot.py.

Важно:
- Нужны BOT_TOKEN и CHAT_ID_HOCKEY (либо предусмотренные config.py альтернативы).
- RUSCORE_API_KEY читается только из окружения; если его не задать, источник Ruscore может отклонять запросы.
- Переобучение происходит на завершённых матчах из истории; до набора минимальной выборки бот использует базовую статистику.
- Существующие predictions.json, stats.json, report.txt и state.json не удаляются.
- Модель сохраняется в hockey_model.pkl.
- Старый ключ Ruscore был записан прямо в исходнике; из соображений безопасности он не перенесён. Если это действующий ключ, замените его/перевыпустите.
